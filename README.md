# 🕯 TSLA бот «первый час»

Бот работает бесплатно на серверах GitHub, компьютер не нужен.
Каждый будний день он сам запускается в 17:30 (Алматы) и присылает в Telegram:

| Время (Алматы) | Что приходит |
|---|---|
| 19:00 | Брифинг: вчерашний макс/мин/закрытие, премаркет, гэп |
| 19:45–20:30 | Сигнал LONG, если цена пробила вверх диапазон первых 15 минут: вход, стоп (≤ 1%), цель |
| после сигнала | «🎯 цель» или «❌ стоп» |
| 21:30 | Итог дня |

Летом (с марта по ноябрь, когда в США летнее время) всё сдвигается на час раньше.

## Установка (10 минут, один раз)

1. Зарегистрируйся на **github.com**.
2. **New repository** → имя `tsla-bot` → **Public** → Create.
   (Public нужен, чтобы GitHub работал бесплатно без лимита. Токен никто не увидит — он хранится в секретах.)
3. **Add file → Upload files** → перетащи ВСЕ файлы из этой папки, включая папку `.github` → **Commit changes**.
   ⚠️ Папка `.github` скрытая. На Mac в Finder нажми **Cmd + Shift + .**, чтобы её увидеть.
4. **Settings → Secrets and variables → Actions → New repository secret**, добавь два секрета:
   - `TELEGRAM_TOKEN` — токен бота от @BotFather
   - `TELEGRAM_CHAT_ID` — `8202101059,1706906299`
5. **Actions** → если есть кнопка «I understand… enable», нажми её →
   **TSLA first hour bot** → **Run workflow** → Run.
   Через 1–2 минуты в Telegram придёт «✅ Тест: бот на GitHub запущен».
   (Ручной запуск вне торгового времени просто шлёт тест и завершается.)

Всё. Дальше бот запускается сам каждый будний день.

## Настройки
Файл `config.yml` можно менять прямо на GitHub (значок карандаша → Commit):
- `max_loss_pct` — максимальный стоп в %
- `reward_risk` — во сколько раз цель дальше стопа
- `allow_short` — `true`, чтобы получать и сигналы на шорт
- `min_score` — сколько условий из 4 должно совпасть

## Проверка на истории
`python backtest.py` — прогоняет стратегию по последним ~60 дням 5-минутных свечей TSLA.

## Важно
- Данные бесплатные (Yahoo Finance). Сигнал приходит в течение ~30 секунд после закрытия 5-мин свечи.
- Это подсказка, а не гарантия. На истории стратегия была около нуля / в небольшом плюсе.
  Начинай с учебного счёта или маленьких сумм и всегда ставь стоп.
